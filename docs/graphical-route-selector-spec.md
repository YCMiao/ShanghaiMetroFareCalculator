# 图形选站与全网路径展示

## 目标

在保留站名输入的同时，提供起点和终点各自独立的图形选站入口。用户先选线路，再从该线路的站点中选择车站；查询后在全网简图中突出显示计算出的路径。

## 约束

- 保持本地 Python 架构：浏览器不计算路径，仍由 `route.py` 计算。
- 站点坐标仅来自保存的上海地铁官方快照；不根据参考图片手工估算位置。
- 换乘边继续为零距离；全网图只表达已计算出的理论最短路径。
- 不引入真实地理底图、实时状态或新的数据来源。

## 交互

- 起点、终点输入框旁各有“按线路选择”按钮。
- 点击后打开同一个选择面板，面板顶部显示当前目标为“选择起点”或“选择终点”。
- 用户选择一条线路后，面板显示该线按官方顺序排列的所有站点；点击站名即回填并关闭面板。
- 查询成功后显示现有文字结果，并在全网 SVG 图中以高亮路径覆盖灰色网络。
